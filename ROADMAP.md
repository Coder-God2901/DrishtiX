## ⚠️ Known Limitations & Tech Debt

### Current Limitations

1. **Scalability**: Single-region deployment (target: multi-region by Q2 2026)
2. **Real-time Processing**: 500ms latency (target: 100ms by Q3 2026)
3. **Offline Support**: Limited mobile offline capabilities (target: full offline by Q2 2026)
4. **Analytics**: Basic BI features (target: Power BI integration by Q3 2026)

### Tech Debt Backlog

- Refactor legacy event processing code
- Migrate from REST to GraphQL for complex queries
- Implement microservices architecture
- Add comprehensive E2E test suite
- Improve database indexing for analytics queries
