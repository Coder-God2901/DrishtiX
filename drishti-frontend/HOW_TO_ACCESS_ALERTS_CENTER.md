# 🎯 Quick Navigation Guide - Alerts & Incident Center

## How to Access the Page

### Step-by-Step:

1. **Launch the app** and login as **Organizer**
2. **Select or create an event** - You'll land on the Event Dashboard

3. In the **left sidebar**, look for the **"Live Operations"** section

4. Click on **"Alerts & Incident Center"** (with Bell icon 🔔)

5. **You're in!** The Alerts & Incident Center page will load

---

## What You'll See

### Immediately upon entering:

- **Header bar** with back button and title "Alerts & Incident Center"
- **Active Incidents counter** (pulsing red badge)
- **Resolved counter** (green badge)

### Main layout:

- **LEFT**: Large incident map (60% width)

  - Colored zones
  - Incident markers (pulsing for active)
  - Legend at bottom-left

- **RIGHT**: Incident list panel (40% width)
  - Filter buttons at top
  - Scrollable incident cards
  - Each card has:
    - Severity dot
    - Incident details
    - Status badge
    - AI recommendation buttons
    - View Details button

---

## Try These Interactions

### 🖱️ Things to Click:

1. **Map markers** - Opens incident drawer with full details

2. **Incident cards** - Each card in the right panel

3. **AI Recommendation buttons** (blue buttons):

   - Example: "Dispatch Medical Team"
   - Opens confirmation modal
   - Click "Confirm" to take action

4. **Filter pills** at top:

   - All / Critical / High / Medium / Low
   - Watch list update instantly

5. **"Show Resolved"** toggle button

   - Includes/excludes resolved incidents

6. **"View Full Details"** button on any card
   - Opens IncidentDrawer with complete info

---

## Watch for Real-Time Updates

- After confirming an action, **status will auto-update** every 5 seconds:

  - New → Action Taken → Teams En Route → In Progress → Resolved

- **Activity log** grows with each action

- Actions taken show as **green checkmarks** ✓

## Demo Tips

### To impress judges:

1. **Point out the severity sorting** - Critical incidents always at top

2. **Show AI recommendations** - Different for each incident type

   - Fire → includes "Call Fire Brigade", "Evacuate Zone"
   - Medical → includes "Dispatch Medical", "Call Ambulance"
   - Crowd → includes "Reroute Attendees", "Open Alternate Gate"

3. **Demonstrate confirmation modal** - Click any action button

   - Shows responsible action-taking process
   - Prevents accidental dispatches

4. **Show the activity log** - Click "View Full Details"

   - Every action timestamped
   - Full audit trail

5. **Highlight real-time updates** - Status badges change color automatically

6. **Filter by severity** - Show focus on critical first

## If Something Doesn't Work

Make sure you:

- Logged in as **Organizer** (not Attendee)
- Selected an event (entered Event Dashboard)
- Looking in the **"Live Operations"** section of sidebar
- Not on the Attendee Dashboard (different interface)
